**我们是谁(一句话)**:一支 AI 深度参与的协作开发工作室——方向、评审、验收由人把关,代码由 AI 与工具链高速交付,每件作品都附带可复跑的测试证据链,证据不实全额退款。

1. **Web 应用与插件全栈**:React/TypeScript/Node/serverless,WordPress 与 Shopify 生态插件;测试先行,三浏览器端到端验证。

③ **交付包**——源码+部署文档+验收清单签收单;
④ **30 天质保**——质保期内缺陷免费修,新需求走书面加价单,绝不悄悄变范围。

**AI 披露**:本工作室全部交付由 AI 深度参与完成,人工负责需求定义、架构裁决、代码评审与验收把关;AI 生成内容按适用法规与平台规则披露。我们相信:有纪律的 AI 协作,交付质量与可验证性优于无测试的人工赶工。

## 作品一|卡A · 钢琴练琴诊断 Web 应用(内部测试版,演示预约制)

- **客户视角**:面向成人自学琴者的练琴诊断工具——连上 MIDI 键盘弹一段,告诉你**错在哪、为什么错、接下来练什么**;无排行、无打卡、无羞辱,只给安静的反馈。
- **技术栈**:React + Vite + TypeScript + Node serverless 代理;Web MIDI;LLM 讲因链(OpenAI 兼容端点,服务端密钥 + zod 契约 + 断网降级模板,讲解永不因外部服务宕机而缺席)。
- **可验证证据**:自动化测试 282 单测(19 文件)+ 54 条端到端用例 × 3 浏览器(Chrome/Edge/Firefox)全绿;自研发版门 10 项检查全过(类型/构建/安全守卫/埋点白名单);全部在档可现场复跑(项目记忆 2026-10-10,commit 1e62bbe)。产品未公开发布,证据即代码,演示可预约。

## 作品二|StoreSweep · Shopify 店铺内容体检

- **客户视角**:一条命令扫完 Shopify 店铺内容的坏链、死图、缺 alt 文案——直接吃 Shopify 后台导出的 CSV,不用装 App、不用授权店铺。
- **技术栈**:Node 18+ 零运行时依赖(纯标准库);JSON/CSV/主题解包三种输入;首跳语义探测(重定向不冒充正常);礼貌限速;另含 Vercel 边缘部署的 OAuth+合规 webhook 参考实现(不存数据)。
- **可验证证据**:202 项自动化测试全绿;托管参考部署线上可访问(https://storesweep-app.vercel.app);证据在档(项目记忆 2026-10-10)。

## 作品三|SiteWarden · WordPress 断链巡查插件

- **客户视角**:装进自己的 WordPress 后台,一键扫全站文章里的断链和重定向——重定向报告**第一跳去了哪**,而不是糊你一个最终状态;扫描在你自己的服务器上跑,站点数据不出站。
- **技术栈**:PHP + WordPress HTTP API(显式禁跟随重定向,逐跳记录);结果存本站数据库;扫描上限可配置,天然防失控。
- **可验证证据**:三层验证在档——结构断言 33 + 行为断言 22 + 真实环境行为验证 17(本地 fixture 服务器实测「登录→扫描→报表」全流程,项目记忆 2026-10-10)。

## 作品四|雁回关 · Godot 叙事卡牌游戏(可玩构建)

- **客户视角**:一款叙事驱动的卡牌游戏:可玩 Windows 构建,卡组数据有完整校验链,数值平衡用蒙特卡洛模拟压测,不是拍脑袋填数。
- **技术栈**:Godot 4(GDScript);引擎内自动化测试(run_tests);蒙特卡洛平衡模拟;卡组引用完整性校验链。
- **可验证证据**:引擎 78 项测试在档;内容评审三席放行(均分 92.17,评审记录在档);可玩构建在仓(products/_spikes/godot-s2-yanhuiguan,build/ + 一键启动脚本)。

## 作品五|UE 5.8 + MCP 引擎自动化管线

- **客户视角**:把虚幻引擎装进自动化流水线:从引擎安装、启动器全自动登录,到 MCP 协议直驱编辑器建场景、布灯、跑工具——游戏引擎也能像 Web 服务一样被脚本指挥。
- **技术栈**:Unreal Engine 5.8.3 + 内置 ModelContextProtocol 插件;Node MCP(Streamable HTTP)客户端;浏览器自动化(桌面应用端到端流程自动化)。
- **可验证证据**:MCP 连通全链实测在档——initialize 握手 → tools/list(52 个工具集)→ call_tool 真实生效(编辑器内生成/查找/删除 Actor 零残留),127.0.0.1:8000 监听实锚(项目记忆 2026-10-10,L2 行为级)。

## 作品六|AI 内容生产线(多席评审 + 机数校验)

- **客户视角**:长篇内容的工业化生产:每一章过三席独立评审(对标席/红队席/受众席),机器指标(字数/对话占比/结构口径)脚本化校验,不合格即返工——AI 写长文不跑偏,靠的是制度不是运气。
- **技术栈**:多席评审编排 + 断路器机制(连续不达标自动升级处置);机数四件套自动提取与声称对拍;修订全程 md5 存证。
- **可验证证据**:连载 14 章、全库约 2.77 万节的生产与放行记录在档;评审返工令与修订闭环全程留痕(项目记忆 2026-10-10)。
